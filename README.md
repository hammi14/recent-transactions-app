# Recent Transactions App

A simple mobile screen built with React Native (Expo + Expo Router) that demonstrates clean architecture and modern development patterns.

## Features
- List of recent transactions with category icons.
- Total calculation at the top.
- Pull-to-refresh to shuffle the list.
- Real-time search by name or category.
- Dark mode toggle.
- Simple fade-in animation for items.

## How to Run
1. Clone this repo.
2. Run `npm install` or `yarn install`.
3. Start with `npx expo start`.


- Used `expo-router` and clean folder separation (`data`, `utils`, `styles`).
- Functional components and hooks.
- `react-native-reanimated` for animations.
- Bonus: Dark mode & tab-based navigation.
